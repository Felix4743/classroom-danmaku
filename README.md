# 课堂弹幕

把课堂变成一场可以发弹幕的直播。老师照常讲 PPT，学生扫码发问题，
弹幕从屏幕底部飘过去 —— 不装 App、不注册、不进班级群。

一个跑在老师电脑上的桌面程序 + 一个局域网服务，学生端就是浏览器。

## 它解决什么

讲课最怕的不是没人提问，是**没有人敢提问**。举手有社交成本，课后围着讲台
又有时间成本。弹幕把这两样都绕开了：匿名、只花两秒、而且看得见别人也在问。

## 怎么用

1. 双击 `课堂弹幕.exe`。会弹出一个窗口，二维码就在最上面。
2. 学生扫码，手机浏览器直接打开，输入昵称就能发。
3. 弹幕叠在 PPT 上飘过去。`Ctrl+Alt+D` 隐藏/显示弹幕层。
4. 下课从托盘菜单退出。记录在 `data/sessions/` 里，跟着 U 盘走。

**不需要联网。** 学生连的是老师电脑自己起的服务 —— 教室 Wi-Fi 就行，
没 Wi-Fi 时老师开一下 Windows 移动热点也一样。只有想让学生用流量也能发，
才需要开公网通道：那条走内置的花生壳穿透，要绑一次账号，之后每次启动自动接上。

一页纸的现场说明见 `deploy/说明.txt`（这份文件也会跟着安装包一起发出去）。

## 开发

需要 Node >= 20。

```bash
npm install
npm test          # 全部测试（含文档交叉引用检查）
npm run dev       # 只起服务，在浏览器里调页面
npm run desktop   # 起完整桌面程序
npm run pack      # 打包到 dist/（单文件 exe + 免安装 zip）
```

## 结构

```
src/main/      Electron 主进程：托盘、弹幕层、本机服务、公网隧道
src/web/       三个页面：投影页 / 老师端 / 学生端
src/shared/    主进程和页面共用：协议、二维码、地址挑选、限流
src/overlay/   叠在 PPT 上的那一层（透明窗口 + Canvas）
tests/         单元测试 + 压测脚本
```
